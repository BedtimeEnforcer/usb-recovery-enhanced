# v0.5.0 实现与交付记录

交付日期：2026-10-26。依据用户确认的第二轮审读处理方案实施。

本版已完成本机无害回归与实际 EXE 界面检查。**尚未进行加强版虚拟机真实感染验收**；用户将自行进行虚拟机测试。本记录不将合成测试、模拟进程操作或旧版验收当成本版真实查杀证明。

## 最终流程

选择 U 盘 → 开始检查（同时检查电脑）→ 查杀与修复 → 预览并恢复 → 保存文件、重启复查。

- 统一列表展示病毒文件、待确认文件、指定启动项与磁盘显示设置。确认病毒默认勾选；不确定项默认保留；纯数字 EXE 等仅凭线索不能隔离。点击处理明确确认勾选项以及保留其余项，不靠用户寻找独立人工核查菜单。
- 文件隔离、进程处理、启动项、策略、服务、计划任务和重现检查分别保存结构化结果。成功、失败、待处理、用户保留互不混淆，不从日志字符串推断成功。
- 文件已隔离但关联启动项失败，失败仍然保留并阻止普通恢复。人工隔离高可疑程序及已知恶意指纹文件也检查明确关联的启动入口。
- 没有管理员权限时可打开系统授权窗口，管理员版本重新扫描。携带原用户 SID 与所选盘，不携带可以直接执行的删除指令；若提权换成另一个账户，新窗口拒绝接管。原窗口与状态保留。
- 结果集中显示处理数量、失败原因和下一步入口。取消立即重启后不再追加提醒弹窗。使用说明保留病毒危害、制作人李晓达及开发缘由，并更新使用步骤。

## 扫描与边界

- 推荐范围包含进程映像、明确 Run/RunOnce 引用、常见落地目录、Windows 子目录、当前用户目录、Program Files 与所选 U 盘。按组轮转处理，电脑与 U 盘每轮各 200000 项；目录深度 128，哈希文件上限 64 MiB，文本/LNK 解析上限 1 MiB。
- 可停止、可继续。继续保留内存中的枚举位置及已检查路径，不从头重扫；关闭程序后需要重新检查。读取 SHA-256 时按数据块响应停止请求，并报告读取进度。底层设备 I/O 阻塞不承诺立即取消。
- 不跟随重解析路径、不读取隔离区、系统回收站或系统卷信息；不覆盖其他用户、未选磁盘、网络路径、压缩包内部和内存注入。读取失败留在详情和日志；关键范围失败阻止恢复。
- 同一路径在扫描会话中去重，扫描器不再对原版大小的非命中文件重复计算哈希。处置前重新计算哈希是必要复核，不能复用扫描时的哈希取代它。

## 判断与处置

- 标准确认隔离仍要求登记大小与 SHA-256 同时匹配，或原版精确诱饵 LNK。伪造 confirmed 不能绕过引擎复核。
- 另外 14 条公开指纹未虚构样本大小，改为单独的已知恶意指纹人工确认隔离路径。隔离文件不代表已完整清除对应家族的内存与其他驻留。
- dat 名称残留、特定可疑位置同名文件、诱饵变体需要明确选择并复核当前路径、大小、哈希及创建时间。数字 EXE、一般脚本与 Autorun 组合线索不因为名称而删除。
- NoDrives 属于磁盘显示设置，不是进程。共享注册表视图去重；HKLM Run 的独立视图不因内容相同而合并。关联删除成功或失败后，统一列表中的未勾选副本不能覆盖实际处理结果。
- 服务与计划任务只检查明确本地文件引用。对用户选择的文件，仅在备份原配置、复核快照后停用直接关联项，不删除服务或计划任务。共享宿主服务不自动处理；正常宿主不按名称结束。停用任务不宣称清理了已经注入的内存或全部宿主。
- 候选互斥体仅作为诊断日志；存在、不存在或不可读取均不能单独判定感染或清除。
- 清理后作 3 次有时限的文件/进程观察，并检查明确关联 Run 引用。任一次观察到重现会保留失败，不会被随后的消失覆盖。这不是常驻防护或对所有驻留方式的保证。

## 恢复与数据保护

- 恢复引擎要求有效扫描上下文、当前卷身份、关键范围检查结果和结构化处理状态。绕开界面调用生产恢复入口但没有上下文时拒绝执行。
- 已确认病毒、已知恶意指纹、未解决的关联失败和重现阻止普通恢复。相关可疑项需明确处理或保留；未确认的启动/显示设置需在同一列表明确选择，不默认为已经处理。
- 选择保留的相关文件在恢复前再次核验。其证据变化后，旧保留决定失效。只有数字文件名的低证据项不会冒充确认病毒阻塞恢复。
- 顶层程序、脚本、快捷方式及包含此类嵌套入口的目录保留原处。其他符合条件的项目可恢复；预览显示暂不恢复的项目，重名保留双方。
- 保留先备份、落盘、校验，再移除源文件的隔离机制；备份失败不继续删。恢复前复核预览、源内容和卷身份，逐步记日志。
- 非空 U+FFFF 容器不删除。只有复核为空且用户单独确认后，使用非递归目录删除操作。Windows 非空目录拒绝语义不等于本次覆盖了所有文件系统并发竞态。
