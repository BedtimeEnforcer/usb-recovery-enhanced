# v0.5.1：U 盘恢复与结果窗口修复

日期：2026-10-26。基于用户虚拟机截图反馈修复三项问题。

## 原因与修改

1. 只扫描电脑时，扫描上下文的盘符为空。随后选择 U 盘恢复，旧判断会对空字符串调用路径规范化，抛出“路径过长或无效”，导致尚未进入恢复预览就被阻断。现在先判断扫描盘符是否为空、是否与当前 U 盘及卷身份相符；无扫描、仅扫描电脑、选择不同盘或更换卷都要求重新扫描杀毒。没有降低恢复前的病毒、失败项与卷身份检查。
2. 未选 U 盘或未扫描所选盘时，显示“请您选择 U 盘后重新扫描杀毒，再恢复文件。”已经选择盘时提供“扫描所选 U 盘”按钮。继续检查切换范围时也不再规范化空盘符。
3. 查杀结果明确区分“病毒已隔离”和“用户文件已恢复”。有已扫描的 U 盘时，把“恢复隐藏文件到根目录”放到结果页首位；点击后预览并确认实际移动。清理后的文件夹列表会刷新；恢复操作保留用户当前选择的隐藏目录。恢复结束记录已移到根目录的数量，不继续显示“尚未恢复”。
4. 工作流窗口使用明确宽度和竖向操作按钮；长日志不再内嵌参与弹窗宽度计算，“查看详情”打开独立的有界滚动窗口。没有自定义操作按钮时，不设置 command-link 模式，避免参数错误。显式初始化 ListView 控件类。

## 验证

原有回归及新增检查均通过：18 基础 + 14 结果 + 57 加强版 + 64 修复 + 68 工作流 + 20 界面，共 **241 个断言检查**。逐项输出见 [verification/v0.5.1](verification/v0.5.1/)。

- 新增从查杀到恢复的贯通测试：临时目录模拟 U 盘根目录及 U+FFFF 容器，放入无害载荷测试指纹、文档、嵌套隐藏文件及根目录同名文件；隔离、复查、预览、实际移动依次执行。验证容器内用户项目移至模拟根目录，文件哈希不变，重名双方保留，嵌套 HIDDEN/SYSTEM 属性清除，结果记录恢复数量。
- 新增空扫描盘符回归：只扫描电脑后选择其他盘恢复，必须返回选择并扫描 U 盘的提示，不能抛出空路径错误。
- 实际原生窗口测试传入超过一万字符的详情和六个操作，结果窗口宽度 786 像素，小于测试主窗口的 900 像素；独立详情窗口宽 760 像素，文本完整保留。
- 对本次 EXE 实际检查启动必阅、尚未扫描时的恢复提示、日志折叠/展开、规则窗口与正常退出；已查看未扫描 U 盘提示的实际截图。

贯通测试使用临时目录及无害文件；进程动作使用 mock，没有运行病毒或修改用户真实 U 盘。真实感染、真实可移动卷及重启后的复现由用户继续进行虚拟机验收。
